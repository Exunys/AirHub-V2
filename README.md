<h1 align="center"> ℹ️  Information  ℹ️<br><br></h1>

This is a universal Lua project featuring advanced targeting, visualization and crosshair systems. Its extensive customizability and modular design make it suitable for experimentation, development and research. This project is completely free, adless and open sourced.

This project is an entirely renewed version of the [old AirHub project](https://github.com/Exunys/AirHub). 

It uses an entirely new [FPS-Styled ESP Module](https://github.com/Exunys/Exunys-ESP) which has been worked on with ambition and pushed to perfection. It also uses an upgraded version of [Exunys's old Aimbot V2](https://github.com/Exunys/Aimbot-V2) which goes by [Aimbot V3](https://github.com/Exunys/Aimbot-V3) for the targeting module.

The UI Library that this project uses is a forked version of an archived UI Library, customized specifically for AirHub V2's standards to provide a polished and highly customizable premium user interface.

Press ***Right Shift*** to open/close the GUI. You can also change this key by opening the settings tab and by navigating to the *Settings* section that is located at the top left side of the GUI.

<h1 align="center">🔬 Educational & Research Purpose 🔬<br><br></h1>

#### <p align="center">AirHub V2 is published as open-source Lua code and can be useful for studying client-side game behavior, visualization, targeting systems and game-security concepts. Developers and security researchers can use the implementation as a reference when testing or improving defensive systems such as server-side validation and anti-cheat mechanisms.</p>

#### <p align="center"> The project is intended for educational, development and authorized research environments. Users are responsible for complying with the rules and terms of the environment in which the code is used.</p>
